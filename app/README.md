# Muzer App 🎵

This directory contains the core application code for Muzer, a collaborative music streaming platform.

## 🚀 Quick Start

1. Install dependencies: `npm install`
2. Sync database: `npx prisma db push`
3. Start dev server: `npm run dev`

## 🧪 Development

The app uses:
- **Next.js** for the framework.
- **Prisma** for database access.
- **Tailwind CSS** for styling.
- **NextAuth** for authentication.

Refer to the root [README](../README.md) for full setup instructions and project overview.
